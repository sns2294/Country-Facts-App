# Country Facts

A geography app for exploring countries around the world — pick a country via dropdown, flat map, or interactive 3D globe, and pull up key facts like capital, population, official languages, religion, and bordering countries.

## Features
- Three ways to explore: search dropdown, clickable flat map, or 3D globe
- Detailed fact card per country: flag, capital, population, region, languages, religion, and clickable bordering countries
- Quiz mode with multiple categories — Flag, Capital, Religion, Language, Geography (map/globe-based), and a Mixed mode pulling from all of them
- Dark mode toggle
- Mobile-friendly with touch support (pan/zoom on map and globe)

## Tech
Built as vanilla HTML, CSS, and JavaScript — no framework, no backend, and **no live API calls**. All country data is stored in the repo under `data/` and read locally, so the site keeps working even if the original data services go down.

## Data sources
`data/` is generated by `scripts/update-data.mjs` from these sources:

| Data | Source | License |
|---|---|---|
| Names, capitals, population, area, languages, currencies, borders, demonyms | [countries.dev](https://countries.dev) (built on GeoNames) | CC BY 4.0 (GeoNames) |
| Form of government, religion shares | [CIA World Factbook](https://github.com/factbook/factbook.json) (`factbook/factbook.json`) | CC0 / public domain |
| Government fallback for gaps | [Wikidata](https://www.wikidata.org) | CC0 |
| GDP (current US$, latest year) | [World Bank](https://data.worldbank.org/indicator/NY.GDP.MKTP.CD) `NY.GDP.MKTP.CD` | CC BY 4.0 |
| Globe country shapes | [world-atlas](https://github.com/topojson/world-atlas) 2.0.2 (Natural Earth) | Public domain |
| Close-up maps on the country pages | [world-atlas](https://github.com/topojson/world-atlas) 2.0.2, 10m resolution (`data/countries-10m.json`, used only by `scripts/build-pages.mjs`, not loaded by the app) | Public domain |
| Flags | [flag-icons](https://github.com/lipis/flag-icons) 7.2.3 | MIT |
| Flat map | `world-map.svg` (in this repo) | — |

Notes on how the Factbook data is used:
- The fact card shows each country's top 2–3 religious groups with their shares (including "Non-religious"). Where the Factbook names religions without percentages, the names are shown without shares.
- The Religion quiz only uses countries whose largest group is an actual religion with a stated percentage.
- Religion and government text is lightly normalized (denominations grouped into broad religions, notes trimmed from government labels).

The 3D globe uses [globe.gl](https://github.com/vasturiano/globe.gl) 2.46.2 and [topojson-client](https://github.com/topojson/topojson-client) 3.1.0, copied into `vendor/` so nothing loads from a CDN.

## Refreshing the data
Requires Node 18+ (no npm install needed):

```
node scripts/update-data.mjs
```

This downloads everything, builds the files in a staging folder, and only replaces `data/` if every source succeeded — a failed run leaves the existing data untouched. It writes `data/meta.json`, which drives the "Data last updated" line in the page footer. Commit the changed `data/` files to publish the refresh.

## Usage
Browsers block loading local data files from `file://`, so serve the folder with any static server, for example:

```
node scripts/serve.mjs
```

then open http://localhost:8000. This server sends no-cache headers so edits always show up; `python3 -m http.server 8000` also works but lets browsers reuse old copies of `app.js` and the data files.

### Country pages
`node scripts/build-pages.mjs` writes `country/`, `sitemap.xml` and `robots.txt`; `--check` verifies they are up to date. `node scripts/check-insets.mjs` verifies that on every page the locator inset holds the whole country (or its ring) with a margin and is not cropped.

### Cache-busting
`index.html` and `app.js` carry content-hash version strings (`app.js?v=…`, `DATA_VERSION`) so a deployed change loads immediately instead of waiting for browser caches to expire; unchanged files keep their URL and stay cached. After changing `style.css`, any script, `world-map.svg` or anything in `data/`, run this before committing:

```
node scripts/stamp-version.mjs          # --check to only verify
```

A pre-commit hook does this for you. Enable it once per clone:

```
git config core.hooksPath scripts/hooks
```
 Or visit the live version via GitHub Pages.

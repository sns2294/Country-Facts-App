# Country Facts

A geography app for exploring countries around the world — pick a country via dropdown, flat map, or interactive 3D globe, and pull up key facts like capital, population, official languages, religion, and bordering countries.

## Features
- Three ways to explore: search dropdown, clickable flat map, or 3D globe
- Detailed fact card per country: flag, capital, population, region, languages, religion, and clickable bordering countries
- Quiz mode with multiple categories — Flag, Capital, Religion, Language, Geography (map/globe-based), and a Mixed mode pulling from all of them
- Dark mode toggle
- Mobile-friendly with touch support (pan/zoom on map and globe)

## Tech
Built as vanilla HTML, CSS, and JavaScript — no framework, no backend. Country data pulled from public APIs ([restcountries.com](https://restcountries.com) and [geoapi.info](https://geoapi.info)).

## Why I built it
I've always liked flipping through the CIA World Factbook, and wanted an interactive version of that experience I could explore and quiz myself with. Built with [Claude Code](https://www.anthropic.com/claude-code) as a hands-on way to learn AI-assisted development.

## Usage
Clone or download the repo and open `index.html` in your browser, or visit the live version via GitHub Pages.
